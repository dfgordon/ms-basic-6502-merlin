# Microsoft BASIC Sources

This is a port of Microsoft BASIC for various early computers with 6502 processors.
Actually, it is a port of a port:

* Microsoft wrote their BASIC in MACRO-10 assembly language on a DEC PDP-10 mainframe
* "Uncle Bernie" (UB) added patches and extensions from the various vendor, and ported to the DASM cross-assembler
* I (DFG) ported the UB package to the Merlin 32 cross-assembler

This package will allow you to actually assemble the code to reproduce object code that matches ROM images found on the web.
It will also allow you to assemble the code in other ways, see notes in the sub-directories.
